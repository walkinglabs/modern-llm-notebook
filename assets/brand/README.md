# Wordmark assets

The README header uses outlined typography in two color variants. All visible letters are SVG paths, so GitHub rendering does not depend on locally installed fonts.

- `modern-llm-wordmark.svg`: light edition, 1600 × 470.
- `modern-llm-wordmark-dark.svg`: dark edition, 1600 × 470.
- Matching PNG exports: 2400 × 705.
- `modern-llm-wordmark-compact.svg` and `modern-llm-wordmark-compact-dark.svg`: narrow-screen editions, 1600 × 580. The README picture selects these below a 600 px viewport width.

Typefaces: [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif), regular, and [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope), medium. Their SIL Open Font Licenses are included in `licenses/`.

The project accent remains `#1D6BF3`; the dark variant uses `#74A7FF`. The wordmark copy is shared between the English and Chinese README editions.
