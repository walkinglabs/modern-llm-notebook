# Partner logo sources

These files identify the partner platforms linked in the course README. Their logos and trademarks belong to their respective owners.

- `modelscope.svg` and `modelscope-dark.svg`: unchanged official light/dark wordmarks from the [ModelScope logo repository](https://modelscope.cn/models/modelscope/logos), revision `be1ad5f763accf93cc4c6cdc579589d0ef736ff3`. The repository provides them for use in projects.
- `amd.png`: the existing project website asset, copied unchanged from `web/src/assets/amd-logo.png`.
- `amd-dark.svg`: unchanged white AMD wordmark from the [AMD Newsroom](https://newsroom.amd.com/media-center/), served at `https://newsroom.amd.com/_astro/amd-header-logo.NP9ywpkQ.svg`.

The README displays each logo at its original aspect ratio and switches variants for dark mode.
